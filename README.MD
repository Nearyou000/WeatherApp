##Погодное приложение
Данное приложение было разработано в рамках учебной практики. Программа позволяет пользователям получать актуальные данные о погоде в различных городах мира, сохранять избранные локации и всегда иметь под рукой необходимую метеорологическую информацию.

##Установка
Для установки программы нужно зайти в раздел releases и установить .apk из самого нового релиза, после чего найти скачанный файл в своём файловом менеджере и нажать на него. В открывшемся окне подтвердить установку. После завершения процесса окно закроется и приложение будет установлено на устройство.

##Требования к устройству:
- Android 8.0 (API 26) или выше
- Доступ к интернету для получения актуальных данных о погоде
- Разрешение на доступ к геолокации (опционально, для автоматического определения местоположения)

##Использование
- Поиск города - введите название в строку поиска
- Просмотр погоды - температура, условия, ветер, влажность
- Избранное - сохраняйте города для быстрого доступа
- Управление - добавляйте/удаляйте города из избранного

##Экраны:
- Главный - текущая погода
- Поиск - поиск городов
- Избранное - сохранённые города

##Разработка
- Kotlin + Jetpack Compose
- Архитектура MVI
- API: WeatherAPI.com
- Минимальная версия: Android 8.0 (API 26)

##Инструкция по сборке проекта
В файл gradle.properties необходимо добавить ваш apikey в следующем формате:
apikey=YOUR_API_KEY
